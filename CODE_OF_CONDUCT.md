# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good intent, and keep discussions focused on the
work. Harassment, discrimination and personal attacks are not tolerated.

To report unacceptable behaviour, open a private security advisory on the repository or contact the
maintainers through the address listed in the repository profile. Reports are handled confidentially.
